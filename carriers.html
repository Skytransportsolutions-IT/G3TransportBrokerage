What we expect on a load

The rules that keep produce claim-free

None of this is unusual for reefer freight. We put it in writing so there are no arguments at the receiver.

Pre-cool and hold set point

Trailer pre-cooled before arrival, continuous cycle unless the rate con says otherwise, and the set point on the confirmation is the set point we expect at delivery.

Seal it and keep it sealed

Seal number recorded on the BOL at origin. It does not come off until the receiver breaks it, and if it does, we need a call before it happens.

Call early, not late

Breakdown, weather, a missed appointment — tell us while there is still time to fix it. A problem we hear about early is a problem we can usually solve.
